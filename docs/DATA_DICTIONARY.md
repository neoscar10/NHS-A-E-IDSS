# Data dictionary

The M06 release contains three datasets: the 35-field provider calendar, the 27-field observed-provider table and the 27-field national table. Keys are `org_code, period` for provider datasets and `period` for national totals.

## Identity and time

| Field | Type | Meaning |
| --- | --- | --- |
| period | datetime | Reporting month start |
| source_period | string | Original published period |
| org_code | string | Normalised reporting organisation code |
| parent_org | string | Recorded parent organisation grouping |
| org_name | string | Recorded organisation name |

## Published counts

All 18 measures are non-negative integers in observed and national records; absent calendar rows contain null counts. Values are monthly counts, not rates.

| Field | Definition |
| --- | --- |
| type1_attendances | Type 1 A&E attendances (forecast outcome) |
| type2_attendances | Type 2 A&E attendances |
| other_attendances | Other A&E department attendances |
| type1_booked_attendances | Type 1 booked appointments |
| type2_booked_attendances | Type 2 booked appointments |
| other_booked_attendances | Other department booked appointments |
| type1_over_4hrs | Type 1 attendances over four hours |
| type2_over_4hrs | Type 2 attendances over four hours |
| other_over_4hrs | Other department attendances over four hours |
| type1_booked_over_4hrs | Type 1 booked attendances over four hours |
| type2_booked_over_4hrs | Type 2 booked attendances over four hours |
| other_booked_over_4hrs | Other department booked attendances over four hours |
| dta_wait_4_12hrs | Patients waiting 4-12 hours from decision to admit to admission |
| dta_wait_12plus_hrs | Patients waiting 12+ hours from decision to admit to admission |
| type1_emergency_admissions | Emergency admissions via Type 1 A&E |
| type2_emergency_admissions | Emergency admissions via Type 2 A&E |
| other_ae_emergency_admissions | Emergency admissions via other A&E departments |
| other_emergency_admissions | Other emergency admissions |

## Provenance

| Field | Type | Meaning |
| --- | --- | --- |
| source_month | string | Source reporting month (YYYY-MM) |
| source_file | string | Source-relative file path |
| source_sha256 | string | Original file fingerprint |
| source_record_number | string | Source record index |

Source attributes and provenance are absent for unreported calendar months; the calendar key remains populated.

## Derived calendar fields

| Field | Type | Meaning |
| --- | --- | --- |
| is_observed | boolean | Published provider record exists |
| observation_state | string | Reported positive, reported zero or absent record |
| observed_last_n_months | integer | Observed months in trailing window including origin |
| positive_last_n_months | integer | Positive Type 1 months in that window |
| history_ready | boolean | Entire history window observed |
| type1_candidate | boolean | Provisional time-aware candidate |
| candidate_status | string | Reason for eligibility classification |
| history_window_months | integer | Configured history length |

The full machine-readable field dictionary and contract are generated by M06. CSV consumers must specify appropriate types; Parquet retains typed fields. Identifiers and audit fields are not continuous predictors.
